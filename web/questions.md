```
Межсайтовый скриптинг (XSS), атака с использованием межсайтовых сценариев – атака, при которой злоумышленник загружает в базу данных веб-сайта вредоносный клиентский код (скрипт JavaScripts, реже HTML, VBScript, ActiveX, Flash). Атаки XSS разделяют на три категории: сохраненные (постоянные), отраженные (непостоянные), основанные на DOM.

Атака с использованием SQL-инъекции – тип атаки, нацеленный на серверы, использующие язык программирования структурированных запросов SQL для управления информацией в базах данных. Базы данных SQL используют операторы SQL для запроса данных, и эти операторы обычно выполняются через HTML-форму на веб-странице. Если разрешения базы данных не были установлены должным образом, злоумышленник может использовать HTML-форму для выполнения вредоносных запросов.

Атака типа clickjacking (англ. «захват клика») позволяет вредоносной странице кликнуть по сайту-жертве от имени посетителя.
- Посетителя заманивают на вредоносную страницу (неважно как).
- На странице есть ссылка, которая выглядит безобидно (например, «Разбогатей прямо сейчас» или «Нажми здесь, это очень смешно»).
- Поверх этой ссылки вредоносная страница размещает прозрачный <iframe> с src с сайта facebook.com таким образом, что кнопка «like» находится прямо над этой ссылкой. Обычно это делается с помощью z-index в CSS.
- При попытке клика на эту ссылку посетитель на самом деле нажимает на кнопку.
```

# Вопросы по безопасности веб-приложений и видам атак для собеседования на Senior Frontend Developer

## 1. Основы безопасности в веб-приложениях
1. Что такое OWASP, и какие цели преследует этот проект?
2. Какие типы атак включены в OWASP Top 10? Приведите примеры.
3. Чем отличаются уязвимости на клиентской стороне от уязвимостей на серверной стороне?
4. Что такое механизмы аутентификации и авторизации? В чем разница между ними?
5. Что означает принцип "минимизации привилегий"? Как он применяется в веб-приложениях?

## 2. Cross-Site Scripting (XSS)

3. Какие методы защиты от XSS вы знаете? В чем отличие между экранированием (escaping) и валидацией данных?
4. Как использовать заголовки безопасности, такие как `Content-Security-Policy` (CSP), для предотвращения XSS?
5. Что такое "JavaScript sandboxing", и в каких случаях он полезен для защиты от XSS?

3. Чем поможет использование заголовка `SameSite` для cookies в контексте CSRF?
4. Как защитить REST API от CSRF-атак?
5. Как улучшить защиту CSRF в SPA-приложениях?

4. Какие существуют ограничения механизма защиты от Clickjacking?
