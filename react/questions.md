# Вопросы по React.js для собеседования на Senior Frontend Developer

## 1. Основы React.js
1. Что такое React.js? Почему он называется библиотекой, а не фреймворком?
2. Чем отличаются Virtual DOM и реальный DOM? Как Virtual DOM улучшает производительность приложения?
3. В чем разница между компонентами-функциями и классовыми компонентами?
4. Что такое JSX? Чем он отличается от обычного JavaScript?
5. Какие основные особенности React выделяют его среди других библиотек и фреймворков?

---

## 2. Компоненты и состояния
1. Что такое состояние (state) в React? Как правильно с ним работать?
2. Чем `props` отличаются от `state`? Почему `state` нельзя менять напрямую?
3. Какой поток данных используется в React? Что такое однонаправленный поток данных?
4. Объясните, как работает `setState()`? Какая разница между синхронным и асинхронным обновлением состояния?
5. Зачем использовать `defaultProps` и `propTypes`? В каких случаях они полезны?

---

## 3. Жизненный цикл компонента
1. Перечислите методы жизненного цикла классового компонента. Как они работают?
2. Чем отличаются `componentDidMount`, `componentDidUpdate` и `componentWillUnmount`?
3. Как правильно использовать `shouldComponentUpdate` для оптимизации производительности?
4. Почему метод `getDerivedStateFromProps` считается антипаттерном, и в каких ситуациях он применяется?
5. Как заменить методы жизненного цикла классовых компонентов с помощью хуков?

---

## 4. Хуки (Hooks)
1. Что такое React-хуки? Какие задачи они решают?
2. Как работают хуки `useState` и `useEffect`? Приведите примеры их использования.
3. Какой порядок вызова хуков в компоненте? Почему важно его соблюдать?
4. В чем разница между хуками `useEffect`, `useLayoutEffect` и `useInsertionEffect`?
5. Что такое `useMemo` и `useCallback`? Как они помогают оптимизировать приложение?
6. Как создать свой собственный хук? Приведите пример.

---

## 5. Работа с DOM в React
1. Как получить ссылку на DOM-элемент? Чем полезен хук `useRef`?
2. Чем `useRef` отличается от `createRef` в классовых компонентах?
3. Как правильно работать с неконтролируемыми компонентами?
4. Что такое Portals? Как они используются для рендеринга элементов вне корневого DOM?
5. В чем разница между контролируемыми и неконтролируемыми компонентами?

---

## 6. Работа с формами
1. Чем отличается управляемый (контролируемый) компонент от неконтролируемого?
2. Как правильно организовать валидацию форм в React (с использованием сторонних библиотек или вручную)?
3. Как обрабатывать события ввода данных в форму с использованием `onChange`?
4. Как использовать хуки, такие как `useState` и `useReducer`, для работы с формами?
5. Какие библиотеки для работы с формами вы использовали (например, Formik, React Hook Form)? Какие преимущества у каждой из них?

---

## 7. React Router
1. Что такое React Router? Как он помогает в реализации маршрутизации?
2. Чем отличаются `BrowserRouter` и `HashRouter`?
3. Как передать параметры в маршруты и как их извлечь?
4. Что такое "динамические маршруты"? Приведите пример их использования.
5. Как использовать `useNavigate` и `useParams` для обработки маршрутов в React Router v6?
6. Чем отличается отложенная загрузка (lazy loading) маршрутов от обычной?

---

## 8. State Management
1. Какие подходы к управлению состоянием вы использовали: React Context API, Redux, MobX? Какие плюсы и минусы у каждого подхода?
2. Когда использовать Context API вместо Redux?
3. Как оптимизировать обновления при использовании Context API (например, с помощью `useMemo`)?
4. Объясните, как работает `Redux` и как он интегрируется с React?
5. Что такое `React Query`? Почему эта библиотека становится популярной в управлении состоянием сервера?

---

## 9. Производительность React-приложений
1. Что такое мемоизация? Как ее использовать в React (например, `React.memo`, `useMemo` и `useCallback`)?
2. Как минимизировать количество перерендериваний компонентов?
3. Как React обрабатывает обновления Virtual DOM? Какие паттерны позволяют ускорить процесс?
4. Что такое "code splitting" и как его реализовать в React с помощью динамических импортов?
5. Какие инструменты вы используете для анализа производительности React-приложений (например, React DevTools)?

---

## 10. Тестирование React-приложений
1. Какие тестовые фреймворки вы используете для тестирования React-приложений (например, Jest, React Testing Library, Cypress)?
2. Что такое snapshot-тестирование и для чего оно используется?
3. Как протестировать пользовательские события (например, клики, ввод текста) в React-компоненте?
4. Чем `shallow` рендеринг отличается от полного (`mount`)? Когда что использовать?
5. Как тестировать компоненты с привязанными к хукам состояниями и эффектами?
6. Как тестировать асинхронные компоненты, взаимодействующие с API?

---

## 11. React Server-Side Rendering (SSR)
1. Что такое Server-Side Rendering (SSR), и какие преимущества оно дает?
2. Чем SSR отличается от Client-Side Rendering (CSR)?
3. Как реализовать SSR в React-приложении с использованием фреймворка Next.js?
4. Какие типы данных считаются "гидратированными" в SSR? Как React обрабатывает гидратацию?
5. Что такое Static Site Generation (SSG), и чем оно отличается от обычной серверной отрисовки?

---

## 12. Работа с API и данными
1. Как вы организуете работу с REST API в React-приложении?
2. Как вы используете `useEffect` для загрузки данных при монтировании (mount)?
3. Какие подходы вы применяете для управления состоянием загрузки, ошибок и данных из API?
4. Что такое GraphQL? Какие библиотеки (например, Apollo или Relay) вы использовали для работы с ним?
5. Какие стратегии кеширования данных вы применяете, чтобы оптимизировать работу с API?

## 13. Возможности нового React
1. Что такое Concurrent Mode? Какие преимущества он предоставляет?
2. Как работает Suspense? Какие задачи он решает?
3. Что означает "React Fiber"? Как оно влияет на перерисовку компонентов?
4. Что такое автоматическое batch-обновление (automatic batching) в React 18?
5. Как реализовать отложенную загрузку компонентов с помощью React.lazy и Suspense?

## 14. Антипаттерны и лучшие практики
1. Какие антипаттерны в React-приложениях вы знаете? Как их избегать?
2. Почему не рекомендуется напрямую изменять состояние через `this.state` или `useState`?
3. Как избежать проп-дриллинга в сложных приложениях?
4. Почему не стоит добавлять много логики в компоненты? Как вынести логику в отдельные модули?
5. Какие подходы вы используете, чтобы писать "чистый" и поддерживаемый код React?

Эти вопросы охватывают как основы React, так и продвинутые темы, включая оптимизацию, тестирование, SSR и управление состоянием.
