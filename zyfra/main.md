# JS

1. Область видимости переменных (var, const, let)?
- `var`: функциональная или глобальная.
- `let` и `const`: блочная область видимости. `const` — неизменяемость ссылки.
2. Что такое замыкание и как оно работает?
- Замыкание — это функция, запоминающая переменные из своей лексической области видимости, имеющая доступ к ним даже после выполнения внешней функции.
3. Как определяется `this`?
- Определяется контекстом вызова:
    - Обычный вызов — глобальный объект (`window`, `global`) или `undefined` в строгом режиме.
    - Метод объекта — сам объект.
    - Конструктор (`new`) — новый экземпляр.
    - Методы (`bind`, `call`, `apply`) вручную задают значение `this`.
4. Отличия стрелочной функции от обычной?
- Стрелочная функция не имеет своего `this`, `arguments`, не может использоваться как конструктор и не имеет `prototype`.
5. Как устроен Event Loop и Call Stack в JavaScript?
- Call Stack («стек вызовов») выполняет вызовы функций один за другим (синхронно).
- Event Loop («цикл событий») следит за очередью задач (макро- и микрозадач) и добавляет их в Call Stack при его освобождении.
6. Чем отличается микрозадача (microtask) от макрозадачи (macrotask)?
- Микрозадачи (`Promise.then`, `queueMicrotask`) выполняются сразу после текущей задачи до следующей макрозадачи.
- Макрозадачи (`setTimeout`, события, `setInterval`) запускаются после выполнения очереди микрозадач.
7. Что такое прототипное наследование и как оно реализуется?
- Прототипное наследование — это механизм, при котором объекты наследуют свойства и методы от других объектов через ссылку на их прототипы.
8. Чем отличаются `Object.create()` и классическое использование `new` для создания объектов?
- `Object.create()` явно задаёт прототип нового объекта.
- Оператор `new` вызовет функцию-конструктор, используя её прототип, и затем вернет новый объект с выполненным кодом функции-конструктора.
9. Что делает метод `hasOwnProperty()`?
- Проверяет, имеет ли объект собственное свойство, не унаследованное по прототипу.
10. Какие методы итерации для массивов существуют?
- Основные: `forEach`, `map`, `filter`, `reduce`, `find`, `findIndex`, `some`, `every`, `includes`.
11. С помощью каких операторов можно объект превратить в массив?
- `Object.entries()`, `Object.keys()`, `Object.values()`.
12. Что такое `Spread` и `Rest` операторы?
- `Spread` (`...`) — «разворачивает» массив и объект в отдельные элементы.
- `Rest` (`...`) — собирает остальные элементы функции или массива в один массив.
13. Что такое чистая функция?
- Функция, результат которой зависит только от входных параметров, не имеющая побочных эффектов.
14. С помощью чего можно оборвать асинхронный запрос?
- Используя объект `AbortController`
15. Как сделать глубокое копирование объекта?
- JSON-методы: `JSON.parse(JSON.stringify(obj))`
- Рекурсивный `Spread`
16. Какие методы будут полезны при манипуляции DOM?
- Методы: `querySelector`, `querySelectorAll`, `append`, `appendChild`, `remove`, `innerHTML`, `innerText`, `textContent`, `classList`, `setAttribute`, методы работы с событиями (`addEventListener`, `removeEventListener`).
17. Какие механизмы для взаимодействия между окнами браузера и iframe?
- postMessage()
- localStorage/sessionStorage
- BroadcastChannel
- SharedWorker
18. Что такое CORS и как его обойти?
- CORS — механизм браузера, ограничивающий междоменный доступ.
- Обойти можно настройкой сервера (установка заголовков `Access-Control-Allow-Origin`) или использованием прокси.
19. Какие паттерны проектирования используются в JavaScript?
- Наиболее распространённые: «модуль», «наблюдатель» (Observer), «одиночка» (Singleton), «фабрика» (Factory), «стратегия» (Strategy), «декоратор» (Decorator), MVC/MVVM архитектурные паттерны.
20. Какие основные уязвимости связаны с JavaScript-кодом?
- Основные: XSS (межсайтовый скриптинг), CSRF (подделка межсайтовых запросов), внедрение вредоносного кода из сторонних библиотек, проблемы безопасности при использовании `eval()`, опасные зависимости пакетов.

# CSS

1. Какие есть подходы к наименованию классов в CSS?
- BEM (блок__элемент--модификатор)
- SMACSS, OOCSS
- Atomic CSS, Utility-first (например, Tailwind CSS)
2. Что такое каскадирование и как работают приоритеты правил в CSS?
- Специфичности селектора
- Последовательности объявления в CSS
- Использования ключевого слова `!important`
3. Для чего нужен и как работает `z-index`?
- Управляет порядком наложения элементов по оси z (по слоям). Элементы с бо́льшим значением `z-index` перекрывают элементы с меньшим значением.
4. Для чего на практике используют `::before` и `::after`?
- Для вставки декоративных элементов, иконок, стрелок, подсказок, создания псевдоэлементов без добавления реального DOM-контента.
5. Как обрезать текст через стили?
- overflow: hidden;
- text-overflow: ellipsis;
- white-space: nowrap;
6. Объясните разницу между `static`, `relative`, `absolute`, `fixed` и `sticky` позиционированием.
- `static`: стандартное без изменения позиционирования.
- `relative`: относительно исходного местоположения.
- `absolute`: относительно ближайшего позиционированного родителя или документа.
- `fixed`: фиксировано относительно окна браузера.
- `sticky`: ведет себя как relative, пока не достигнет указанной позиции, затем становится как fixed.
7. Что такое `Reflow` (перекомпоновка) и `Repaint` (перерисовка) в браузере?
- Reflow — перерасчёт и перестроение макета страницы (например, при изменении размеров элемента).
- Repaint — перерисовка элемента без изменения геометрии (например, изменение цвета фона).
8. Какие инструменты вы используете для анализа и оптимизации `Reflow` и `Repaint`?
- DevTools (Performance, Rendering панели браузера)
- Lighthouse, PageSpeed Insights, WebPageTest
9. Какие есть решения для позиционирования группы элементов?
- Flexbox
- CSS Grid
- Inline-block элементы
- Floats (устаревшее решение)
10. Какие есть востребованные фичи в css-препроцессорах?
- Вложенность (Nested CSS)
- Переменные и миксины
- Наследование и расширения (`extend`)
- Функции и математические операции
- Импорты и модульность


# Angular

1. Какие хуки жизненного цикла компонентов есть в Angular?
- `ngOnChanges`, `ngOnInit`, `ngDoCheck`, `ngAfterContentInit`, `ngAfterContentChecked`, `ngAfterViewInit`, `ngAfterViewChecked`, `ngOnDestroy`.
2. Как работает механизм обнаружения изменений в Angular?
- Angular использует древовидную архитектуру Change Detection для проверки и применения изменений состояния компонентов. По умолчанию запускается автоматически при асинхронных событиях и вводе пользователя.
3. В чём отличие `Default` и `OnPush` стратегий обнаружения изменений? Как вручную инициировать обнаружение изменений в Angular?
- `Default`: проверяет всегда.
- `OnPush`: проверка только при изменении входных ссылок (`@Input`) или явном ручном запуске.
- Ручная инициация: метод `detectChanges()` или `markForCheck()` из сервиса `ChangeDetectorRef`.
4. Что такое зоны `zone.js`, и какую роль они играют в Angular?
- Библиотека для отлавливания асинхронных операций, автоматически запускает механизм обнаружения изменений Angular после асинхронных событий и манипуляций с DOM, «перехватывая» события.
5. Расскажите о концепции Dependency Injection в Angular?
- DI позволяет передавать зависимости в компоненты и сервисы автоматически, облегчая тестирование и повторное использование кода. Важна для построения гибкой, модульной структуры приложения.
6. Какие существуют подходы для работы с формами в Angular?
- Template-driven формы (через шаблоны и директивы — автоматически двусторонняя привязка).
- Reactive формы (более управляемые; явно описываются в code-behind через FormGroup, FormControl).
7. Что такое пайпы, для чего их удобно использовать? Чем отличается чистый (`pure`) пайп от нечистого (`impure`)?
- Функции для преобразования отображаемых данных в шаблонах (например, форматирование даты и чисел).
- Pure: кешируются и вызываются только при изменении входных параметров.
- Impure: вызываются на каждом цикле обнаружения изменений (даже если параметры не изменились).
8. Какую роль играет библиотека RxJS в Angular?
- Реактивное программирование, управление асинхронными потоками данных и реакция на события, мощные возможности для потоков и обработки событий.
9. В чём разница между `Observable` и `Promise`? Какие особенности в `Subject`, `BehaviorSubject`, `ReplaySubject` и `AsyncSubject`?
- `Observable`: ленивый, поддерживает несколько значений, отмену подписок, операторы преобразования.
- `Promise`: нет отмены, возвращает одно значение, запускает операции сразу.
- `Subject`: одновременный Observable и Observer, широковещательная рассылка.
- `BehaviorSubject`: хранит последнее значение, всегда его передаёт новым подписчикам.
- `ReplaySubject`: сохраняет и передаёт указанное количество последних значений новым подписчикам.
- `AsyncSubject`: выдает только финальное значение после завершения.
10. Что вы знаете о современных Angular-фичах (signal, standalone, new template syntax)?
- Signals: новая реактивная примитивность для оптимизации и упрощения Change Detection.
- Standalone компоненты: компоненты без обязательного объявления в модулях (NgModules).
- Новый синтаксис шаблонов: упрощенная запись структурных директив (*defer, @if, @for), упрощение использования директив и повышения читаемости.
