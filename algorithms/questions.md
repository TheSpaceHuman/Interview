# Вопросы по алгоритмам для собеседования на Senior Frontend Developer

## 1. Общие вопросы
1. Что такое сложность алгоритма? Расскажите про время выполнения (Time Complexity) и использование памяти (Space Complexity).
2. Объясните, что такое `Big O` нотация и приведите примеры её использования.
3. Какие типы структур данных вы знаете? Когда и зачем их использовать?
4. Расскажите о наиболее эффективных способах для поиска элемента в массиве.
5. Объясните разницу между итеративными и рекурсивными решениями.

## 2. Поиск пар элементов с заданной суммой
**Задание:**
Дан массив чисел и целевое число. Найдите все пары чисел, сумма которых равна заданному числу.

- Вопросы к заданию:
  1. Какая сложность алгоритма описанного решения? Можно ли её оптимизировать?
  2. Можете ли реализовать линейное решение (`O(n)`) для задачи? Опишите подход.
  3. Как поведение алгоритма изменится при наличии повторяющихся чисел?

**Пример:**
- Массив: `[2, 4, 1, 5, 9, -3]`, целевое число: `6`
- Ожидаемый результат: `[[2, 4], [1, 5], [9, -3]]`

## 3. Сортировка массива и нахождение K наибольших элементов
**Задание:**
Отсортировать массив чисел и вывести `K` наибольших элементов.

- Вопросы к заданию:
  1. Какие способы сортировки можно использовать? В чём их различие?
  2. Можно ли реализовать задачу без полного сортирования массива (оптимизация для `K` элементов)?
  3. Какое решение лучше для больших массивов?

**Пример:**
- Вход: `[100, 50, 0, 150, 100, 0, -30, 70]`, `K = 3`
- Ожидаемый результат: `[150, 100, 100]`

---

## 4. Оптимальное слияние двух отсортированных массивов
**Задание:**
Слить два отсортированных массива в один отсортированный массив.

- Вопросы к заданию:
  1. Какая сложность алгоритма слияния?
  2. Как можно улучшить производительность, если массивы очень большие?
  3. Какие возможны узкие места при использовании большого количества памяти?

**Пример:**
- Вход: `[1, 4, 7]` и `[0, 3, 5, 9]`
- Выход: `[0, 1, 3, 4, 5, 7, 9]`

## 5. Печать древовидной структуры
**Задание:**
Реализовать функцию, которая принимает дерево и распечатывает его структуру.

**Пример дерева:**

```markdown
- Вещи
    - Одежда
        - Мужская
        - Женская

- Хобби
    - Велосипеды
        - Горные

    - Мангалы
        - Железные
        - Стальные

```

- Вопросы к заданию:
  1. Какая рекурсивная техника может быть полезна для визуализации дерева?
  2. Как можно распечатать дерево с использованием итеративного подхода (без рекурсии)?
  3. Как модифицировать алгоритм для вывода узлов дерева с уровнями отступов?

## 6. Проверка правильности скобочной последовательности
**Задание:**
Дана строка, содержащая только скобки `(` и `)`. Определите, является ли она корректной скобочной последовательностью.

- Вопросы к заданию:
  1. Какую структуру данных вы бы использовали для расширенного варианта (с несколькими типами скобок)?
  2. Как вы оцениваете производительность алгоритма? Можно ли его улучшить?
  3. Какие ошибки при реализации подобных алгоритмов являются наиболее частыми?

**Пример:**
- Вход: `"(())"`
- Выход: `true`

**Пример некорректной строки:**
- Вход: `")(()"`
- Выход: `false`

## 7. Подсчёт количества островов
**Задание:**
Дан двумерный массив, где `'1'` обозначает сушу, а `'0'` воду. Подсчитайте количество "островов".

- Вопросы к заданию:
  1. Какая структура данных подойдёт для управления обходом массива в этой задаче?
  2. Какие подходы лучше всего подойдут: DFS, BFS, рекурсия?
  3. Какие варианты оптимизации можно предложить для больших массивов?

**Пример:**
- Вход:
```plaintext
[
    ['1', '1', '1', '1', '0'],
    ['1', '1', '0', '0', '0'],
    ['1', '0', '0', '0', '0']
]
```

- Выход: `1`

## 8. Определение и загрузка зависимостей
**Задание:**
Напишите функцию, которая принимает объект зависимостей и выводит порядок их подключения (дочерние перед родительскими).

**Вопросы:**
1. Какую структуру данных лучше использовать для выполнения топологической сортировки?
2. Какая сложность алгоритма определяется в данном случае?
3. Что нужно учитывать при обработке циклических зависимостей?

**Пример:**
- Вход:
```javascript
const lib = {
    a: { x: true, y: true },
    b: { z: true }
};
```
- Ожидаемый результат: `x -> y -> z -> a -> b`
